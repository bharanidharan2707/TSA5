# Spam Message Detector

## About

A Machine Learning application that identifies whether a message is Spam or Not Spam.

## Features

* Enter text messages.
* Detect spam messages.
* Display prediction results.
* Highlight suspicious words.

## Technologies

* Python
* Scikit-learn
* NLP
* Streamlit

## Run

```bash
pip install -r requirements.txt
streamlit run app.py
```
